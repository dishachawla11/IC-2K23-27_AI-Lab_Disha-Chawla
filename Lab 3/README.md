## Aim
To understand and perform basic data analysis and preprocessing operations using Python libraries such as NumPy and Pandas.

## Simple Concepts

### 1. Exploratory Data Analysis (EDA)
EDA is the process of examining and understanding a dataset using statistical methods and visualizations. It helps identify patterns, missing values, duplicate records and relationships in the data.

### 2. NumPy
NumPy (Numerical Python) is a Python library used for numerical calculations and mathematical operations. It provides support for arrays, matrices and multidimensional data.

### 3. Pandas
Pandas is a Python library used for data manipulation and analysis. It provides two main data structures: Series and DataFrame, which help organize and manage data in rows and columns.

### 4. Data Preprocessing
Data preprocessing is the process of cleaning and transforming raw data into a suitable format for analysis and machine learning. It includes handling missing values, removing duplicates, encoding categorical data and feature scaling.
