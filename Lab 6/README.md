## Aim
To understand the basic concepts of Linear Regression, Neural Networks and PyTorch.

## Simple Concepts

### 1. Linear Regression
Linear Regression is a supervised machine learning algorithm used to predict continuous numerical values. It identifies the relationship between input and output variables using a straight-line equation.

### 2. Neural Network Fundamentals
A Neural Network is a machine learning model inspired by the human brain. It consists of interconnected neurons arranged in input, hidden and output layers. It is used to learn patterns from data and make predictions.

### 3. PyTorch Basics
PyTorch is an open-source Python library used for Machine Learning and Deep Learning. It provides tensors for numerical operations and tools for building and training neural networks.
