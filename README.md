# AI Water Jug Problem
This solves the classic **Water Jug Problem** using **Breadth-First Search (BFS)** in Python.

## Problem
We have two jugs:
* Jug 1: 4 litres
* Jug 2: 3 litres
* Target: 2 litres
The program finds a sequence of steps to get exactly 2 litres of water.

## Concepts Used
* Python
* Breadth-First Search (BFS)
* Queue
* Set

## Goal
To reach the target amount of **2 litres** using the available jug operations.
